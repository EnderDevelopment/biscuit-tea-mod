# BiscuitTeaMod

BiscuitTeaMod is a Minecraft mod that adds new food items to the game: cookies, gingerbread, and tea. These items can be crafted and consumed by players, providing a simple and enjoyable addition to the game's food variety. The mod is designed for Minecraft version 1.12.2 and requires Forge to be installed.

## Install

1. Download the BiscuitTeaMod file from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded file in the `mods` folder of your Minecraft installation directory.
3. Launch Minecraft and ensure that Forge is installed and configured correctly.

## Use

1. Launch Minecraft with Forge installed.
2. Open the crafting menu.
3. Use the crafting recipes to create cookies, gingerbread, or tea.
4. Consume the crafted items to restore hunger and saturation.
